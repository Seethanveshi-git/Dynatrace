API: Update dashboard
Method: PUT
Endpoint: /api/config/v1/dashboards/{id}
Scope: WriteConfig
Doc: https://docs.dynatrace.com/docs/dynatrace-api/configuration-api/dashboards-api/put-dashboard
Run:
- Set DYNATRACE_BASE_URL
- Set DYNATRACE_API_TOKEN
- Set DYNATRACE_DASHBOARD_ID
- Prepare update payload JSON and set DYNATRACE_PAYLOAD_PATH (or keep default)
- node .\update-dashboard.js
