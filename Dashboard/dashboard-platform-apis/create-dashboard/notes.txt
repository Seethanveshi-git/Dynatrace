Platform API: Create dashboard document
Method: POST
Endpoint: /platform/document/v1/documents
Auth: OAuth bearer token (platform API)
Important:
- Payload shape can vary by dashboard document schema/version.
- Use the document service Swagger in your tenant to confirm exact payload fields.
Run:
- Set DYNATRACE_DOCUMENT_PAYLOAD_PATH to your real payload file
- node .\create-dashboard.js
