API: Get dashboard sharing config
Method: GET
Endpoint: /api/config/v1/dashboards/{id}/shareSettings
Scope: ReadConfig
Doc: https://docs.dynatrace.com/docs/dynatrace-api/configuration-api/dashboards-api/get-sharing-config
Run:
- Set DYNATRACE_BASE_URL
- Set DYNATRACE_API_TOKEN
- Set DYNATRACE_DASHBOARD_ID
- node .\get-sharing-config.js
